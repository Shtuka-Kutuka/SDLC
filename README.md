## Описание

Десктопная утилита на Java (Swing) для расчёта суточной нормы протеина.
Пользователь вводит вес и единицы измерения (кг/фунты), программа выдаёт
рекомендуемую суточную норму белка. Реализована по шаблону **MVC с активной
моделью** (паттерн «Наблюдатель»).

## Возможности

- Ввод веса и выбор единиц измерения (кг / фунты).
- Расчёт суточной нормы протеина (1.6 г на 1 кг массы тела).
- Сохранение последних введённых данных и их восстановление.
- Отображение результата на главной форме.
- Валидация ввода с сообщением об ошибке.

## Использование

    Запустить приложение.

    Нажать «Ввести данные».

    Ввести вес, выбрать единицы (кг/фунты), подтвердить.

    На главной форме отобразится результат.

    При повторном вводе последние данные восстанавливаются.

    При некорректных данных выводится сообщение об ошибке.
